# Freedom CQA — фронтенд

React + TypeScript + Vite. Работает только с настоящим бэкендом (моков больше нет).

## Запуск
1. Запустить бэкенд (`backend/`, порт 8080) и дождаться `Started CqaApplication`.
2. В этой папке:
   ```
   npm install
   npm run dev
   ```
3. Открыть http://127.0.0.1:5173

Все запросы `/api/...` Vite сам пересылает на `http://localhost:8080` (см. `vite.config.ts`), поэтому `.env` не нужен.
Бэкенд на другом адресе: `set CQA_BACKEND=http://адрес:8080` перед `npm run dev`.

## Структура
```
src/api.ts            все запросы к бэкенду и типы ответов
src/host.ts           где запущено приложение: отдельно или внутри Dynamics 365 (параметр data, адрес API из config.js)
src/ui.tsx            общие элементы: бейджи баллов и статусов, загрузка, ошибки, пустые состояния
src/App.tsx           меню, переключатель роли, маршруты
src/styles.css        все стили; цвета в :root (--brand — фирменный зелёный)
src/pages/
  Dashboard.tsx       Обзор (ОКК)
  Conversations.tsx   список диалогов, фильтры, загрузка и оценка по кнопке
  ConversationCard.tsx карточка: балл, критерии с обоснованием, стенограмма, аудио, апелляция
  Appeals.tsx         апелляции и решение ОКК
  Checklist.tsx       чек-лист и редактор версий
  Models.tsx          выбор модели AI по языкам + памятка
  Cost.tsx            стоимость AI: цены моделей, цена оценки по языку/длине/модели, план теста
  Operators.tsx       рейтинг (ОКК) / мой рейтинг (оператор)
  Corrections.tsx     база ошибок AI
  Results.tsx         сдача results.json: загрузить → оценить → сохранить
```

## Dynamics 365 (HTML-компонент)

Приложение собирается как набор веб-ресурсов Dataverse и импортируется готовым решением.

```
npm run pack:d365
```
Результат — `d365/FreedomCQA_1_0_0_0.zip` (неуправляемое решение, издатель QUARK, префикс `fcqa`). В нём 5 веб-ресурсов:

| Веб-ресурс | Что это |
|---|---|
| `fcqa_/cqa/index.html` | страница приложения — её добавляют на форму, панель мониторинга или в карту сайта |
| `fcqa_/cqa/cqa.js`, `fcqa_/cqa/cqa.css` | код и стили (одно имя на всё время, ссылки относительные) |
| `fcqa_/cqa/config.js` | адрес бэкенда этой установки: `window.CQA_CONFIG = { apiBase: 'https://…/api' }` |
| `fcqa_/cqa/favicon.svg` | иконка |

**Установка**
1. make.powerapps.com → Решения → Импорт решения → `FreedomCQA_1_0_0_0.zip` → Опубликовать все настройки.
2. Открыть веб-ресурс `fcqa_/cqa/config.js`, вписать адрес бэкенда (HTTPS), опубликовать.
3. В `application.properties` бэкенда `cqa.cors-origins` уже разрешает `https://*.dynamics.com`.
4. Добавить `fcqa_/cqa/index.html` туда, где нужно:
   - **карта сайта / панель** — полное приложение с меню;
   - **форма записи** (например, обращение) — с «Пользовательским параметром (data)» `conversationId=p1-ru-001&embed=1`: откроется только карточка диалога, без меню (меню даёт сама Dynamics).
   Другие параметры `data`: `role=OPERATOR`, `operatorId=3`.

Внутри Dynamics экраны открываются после `#` (`index.html#/conversations/p1-ru-001`): у веб-ресурса один адрес, поэтому используется hash-маршрутизация. Шрифт Inter подгружается с Google Fonts; если он заблокирован политикой, используется Segoe UI — шрифт самой Dynamics.

Проверено локально: сборка открыта по пути `/WebResources/fcqa_/cqa/index.html?data=conversationId%3Dp4-ru-003%26embed%3D1` с бэкендом на другом адресе (CORS) — карточка открывается без меню, полное приложение работает с меню. Импорт в настоящую среду Dataverse не проверялся: нет доступа к среде.
